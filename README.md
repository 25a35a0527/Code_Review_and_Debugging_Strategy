### 🎯 Objective

The main objective is to establish a structured and repeatable process for identifying defects early, resolving issues efficiently, and maintaining a reliable and maintainable codebase.

### 🔍 Debugging Methodology

The debugging process follows five stages:

1. **Identify** – Reproduce and understand the defect.
2. **Isolate** – Find the specific component causing the issue.
3. **Resolve** – Fix the root cause and add regression tests.
4. **Verify** – Confirm the fix and check for side effects.
5. **Prevent** – Document the root cause and reduce future recurrence.
